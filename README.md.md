# 1% Better - CLI Habit Tracker

A lightweight, terminal-based Python application for tracking daily habits and building long-term streaks. 

## Features
- **Add Habits:** Easily add new daily goals.
- **Track Streaks:** Watch your streak grow as you complete habits daily.
- **Persistent Storage:** Saves your progress locally using JSON.

## How to Run
1. Ensure you have Python installed on your system.
2. Clone this repository to your local machine.
3. Open your terminal in the project directory.
4. Run the script:
   ```bash
   python tracker.py
